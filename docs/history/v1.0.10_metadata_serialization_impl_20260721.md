# V1.0.10 Metadata Serialization 实现记录

## 目标

实现 ADR-0031 Metadata Serialization Layer，统一 StageDescriptor / StageInfo / RuntimeMetadata / ConditionEval 的序列化逻辑到独立模块。

## 关键设计

- **Canonical API**: `serialize_xxx()` 函数是 canonical implementation，`to_dict()` methods 仅是 facade (R1 约束)
- **Schema 稳定性**: R4 stability test 守护 keys 不变，V1.0.10 不引入 schema_version (V1.1 deferred)
- **Lazy import**: `to_dict()` 方法内 lazy import 避免循环依赖
- **Backward compat**: V1.0.4 ConditionEval.to_dict() 保留，V1.0.9 _descriptor_to_dict 改为 deprecated alias
