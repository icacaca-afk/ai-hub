## 五、观察项（非阻塞，留档）

1. 发行版采用平铺顶层包（core/router/cli/planner/providers/adapters），无 `ai_hub` 顶层命名空间。模块文档字符串中的 `python -m ai_hub.adapters.marvis_mcp_server` 仅在源码树场景成立；wheel 安装态的正确入口是 `python -m adapters.marvis_mcp_server`。建议后续统一入口命名。
2. MCP `serverInfo.version` 报告的是 MCP SDK 版本（如 1.29.0），不是 runtime 1.0.13。
3. 启动时出现一条来自第三方依赖链（pydantic_settings ← mcp）的 `IncompleteFieldDefinitionWarning`，非本项目代码产生。
